# لوحة مدير مهرة (ويب)

Next.js (App Router) عربية RTL. تعمل فوق نفس مخطط ومنطق `mahra/supabase` عبر Postgres حقيقي في الذاكرة (PGlite) أثناء التطوير، فتُستدعى دوال القاعدة الفعلية (`staff_set_commission_paid`, `staff_review_proof`, `staff_review_document`, `staff_set_provider_status`…).

```bash
cd mahra/apps/admin && npm install
npm run dev            # http://localhost:3100  (بيانات تجريبية تُبنى عند كل إقلاع)
npm run typecheck && npm run lint
```
للتشغيل المُجمَّع (`next start`) يلزم `ALLOW_INSECURE_DEV_AUTH=1`؛ بدونه ترفض اللوحة العمل بحماية من تشغيلها بلا دخول حقيقي.

## الصفحات
| الصفحة | ما تفعله |
|---|---|
| `/` لوحة القيادة | «يحتاج انتباهك» (عمولات متأخرة، إثباتات، مزودون بانتظار الاعتماد) + أرقام |
| `/providers` | خط الاعتماد، تصفية بالحالة، نقطة خضراء/حمراء + ما ينقص كل مزود |
| `/providers/[id]` | قبول/رفض الوثائق بسبب، اعتماد، إيقاف، إعادة تفعيل مع override، إلغاء نهائي، سجل التدقيق |
| `/commissions` | لوحة «هل سُدّدت؟ نعم/لا»، مراجعة الإثباتات (ما صرّح به المزود مقابل ما قرأه المسح) |
| `/revenue` | العمولات المحصَّلة حسب الشهر والفئة والمزود |
| `/vat` | مخصصات الضريبة 5% |

## ما اختُبر (في متصفح، على المنطق الحقيقي)
بوابة الاعتماد (تتعطل قبل قبول الوثائق)، «نعم» تسجل الضريبة و«لا» تحذفها، اعتماد إثبات يدوياً، override لموقوف، لا اعتماد لمزود ناقص، الإلغاء نهائي، وبلا أخطاء كونسول.

## ما ينقص قبل الإنتاج
- **دخول حقيقي ومدراء متعددون بأدوار.** الآن موظف تطوير ثابت بدور مالك.
- استبدال PGlite بقاعدة حقيقية (الاستضافة تنتظر قرار المنطقة).
- عرض ملفات الوثائق والإثباتات من التخزين، وتخزين الإثباتات.
- الصفحات المؤجلة: الطلبات، المحادثات والتصعيد، الوكلاء، روبوت الاستقطاب، سجل التدقيق العام.
- النسخة الإنجليزية (النصوص مركزة في `src/lib/strings.ts`).
