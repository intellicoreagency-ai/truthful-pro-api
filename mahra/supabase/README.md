# مهرة — الخلفية (Postgres)

مخطط محمول يعمل على Supabase أو أي Postgres 15+. القواعد المالية والحالات تُفرض في قاعدة البيانات لا في التطبيقات.

```bash
cd mahra/supabase && npm install && npm test   # 52 اختباراً على Postgres حقيقي (PGlite)
```

## الملفات
| الملف | المحتوى |
|---|---|
| `migrations/…001_core.sql` | الجداول والأنواع |
| `migrations/…002_logic.sql` | العروض، القبول الذرّي، العمولات، الإثبات، الإيقاف الآلي، override |
| `migrations/…003_security.sql` | RLS، سحب الصلاحيات الافتراضية، منح الحد الأدنى |
| `seed.sql` | الوكلاء الخمسة عشر وفئات الخدمة الأولى |
| `tests/run.mjs` | سيناريو كامل: وثائق ← اعتماد ← عروض ← قبول ← دفعات ← عمولة ← إثبات ← إيقاف |

## قواعد مفروضة في القاعدة
- السعر النهائي = سعر المزود + عمولة الفئة (تُحسب بالفلس وتُجمَّد وقت العرض)؛ المزود لا يحددها.
- 3 عروض كحد أقصى لكل طلب؛ قبول عرض يغلق الباقي ذرّياً.
- العميل لا يقرأ سعر المزود ولا عمولته؛ ولا رقم المزود قبل القبول.
- العمولة 20% على **كل دفعة يسجل المزود تحصيلها**، بالتراكم دون انحراف تقريب، وتُستحق بعد 3 أيام عمل.
- الاعتماد مستحيل قبل قبول الرخصة وعقد الإيجار وتوفر الهاتف والواتساب والخريطة والفئات والتغطية.
- إثبات التحويل يُسجَّل «مدفوع» آلياً فقط إذا طابق المبلغ والحساب المستفيد ومرجعٌ غير مكرر؛ وإلا «بحاجة مراجعة».
- الإيقاف الآلي للمتأخر الذي لم يرفع إثباتاً؛ للمدير override بمدة؛ والحساب الملغى لا يعود.
- كل تغيير حالة لمزود أو عمولة يُسجَّل في `audit_log`.

## افتراضات تنتظر تأكيد المالك
1. تُستحق العمولة بعد 3 أيام عمل من **تسجيل المزود للتحصيل** (لا من قبول العرض).
2. عطل الدولة (العيد واليوم الوطني…) تُدخَل يدوياً في `public_holidays` لأن تواريخها تُعلن سنوياً.
3. وعاء ضريبة الـ5% = قيمة العمولة، بانتظار تأكيد المحاسب (العمود `base_kind` يسجل الوعاء).
4. المدير المالي يعدّل العمولات، والدعم يوقف ويعيد، والمراجع يقبل الوثائق.

## لم يُنفَّذ بعد
- جدولة `suspend_overdue_providers()` يومياً (pg_cron أو Schedules).
- خدمة OCR التي تستدعي `apply_proof_ocr`، وروبوت الاستقطاب، وخدمة الوكلاء والصوت.
- التخزين (الرخص، صور الأعطال، إثباتات التحويل) وسياساته.
- المنطقة: لم أتأكد من توفر منطقة إماراتية في Supabase؛ المخطط محمول ويمكن نقله.
