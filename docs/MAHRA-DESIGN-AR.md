# دليل تصميم «مهره» لـ Claude

اقرأ هذا الدليل عند تصميم أي واجهة في تطبيق «مهره» أو تعديلها. اقرأ **القسم والصورة المرتبطين بالتعديل فقط**. الصور وهذا الملف خاصان بالمشروع ولا يُنشران خارجه (`docs/mahra-design/` مستثناة من git).

> **مهم:** الصور تقريب للفكرة وإلهام للاتجاه، وليست تصميمًا نهائيًا ولا قيدًا. يحق لـ Claude تحسين التخطيط والتفاصيل ما دامت الهوية والمبادئ في القسمين 1 و2 محفوظة.

> هذا الدليل لتطبيق الهاتف «مهره | بيت». ملفا `DESIGN.md` و`PRODUCT.md` في جذر المستودع يخصان موقع Truthful Pro ولا ينطبقان هنا.

## 1. التوجيه العام

- **صمّم حول حاجة العميل.** من الرئيسية: تحدّث بضغطة واحدة، أو اختر خدمة فتصل إلى مختصها بضغطتين. رتّب الخدمات بحسب أولويات يومه، بدءًا بالبيت والطعام. عند انتقاله إلى مختص ينتقل سياق حديثه معه (لا يكرر شيئًا).
- **الصوت أسهل حركة في التطبيق.** زر «تحدّث مع مهره» ثابت أسفل الشاشة في متناول الإبهام. تتحرك الكرة الزجاجية عند الاستماع، وتتفاعل الموجة عند الرد، مع نص واضح للحالة وزر لإيقاف الحديث.
- **اللغة.** مهره تتحدث بلغة العميل وتتبع تغيّرها أثناء المحادثة.
- **الصوت: Veda.** اختبر دعمه لكل لغة قبل إعلان توفرها.

## 2. الهوية البصرية (من الصور)

| العنصر | القرار |
|---|---|
| الخلفية | كحلي ملكي داكن مع توهج ذهبي/أزرق خافت |
| البطاقات | زجاج مقروء (تعتيم كافٍ خلف النص، حد رفيع فاتح) |
| الإجراء الرئيسي | ذهبي دافئ (تدرّج أزرق→ذهبي في زر الدخول) |
| الكرة الزجاجية | رمز مهره الثابت: صوتي، تتحرك حسب الحالة |
| الاتجاه | RTL أولًا، والإنجليزية تعكس التخطيط بلا كسر |
| الأيقونات | خطية بسيطة؛ أيقونة ملوّنة واحدة لكل خدمة |

## 3. الصور المرجعية (إلهام لا قيد)

الترتيب كما أُرسلت. التسمية بحسب **محتوى** كل صورة.

### الصورة 1 — الدخول
![الدخول](mahra-design/01-login.jpg)
**القرار:** حقلان (اسم مستخدم/بريد + كلمة مرور بإظهار/إخفاء)، زر دخول رئيسي ذهبي، ثم Face ID وApple كبدائل ثانوية. لا شيء آخر يزاحم الدخول.

### الصورة 2 — الرئيسية الصوتية (مرجع الصفحة الرئيسية)
![الرئيسية](mahra-design/02-voice-home.jpg)
**القرار:** الكرة والميكروفون في المنتصف، شريحة اختصارات أفقية («تحدث معي»، «جدول اليوم»…) تختصر البدء، ودوك سفلي. الحساب أعلى الشريط.

### الصورة 3 — المحادثة الصوتية (مرجع المحادثة)
![المحادثة](mahra-design/03-voice-chat.jpg)
**القرار:** شريط سفلي زجاجي زر الميكروفون في وسطه أكبر الأزرار، موجة صوتية تتفاعل، واقتراحات سريعة فوق الشريط. هذا هو الشريط السفلي المعتمد للتطبيق.

### الصورة 4 — استوديو المختصين (مرجع عرض المختصين)
![المختصون](mahra-design/04-specialists-studio.jpg)
**القرار:** بطاقة لكل مختص: أيقونة ملوّنة + الاسم والدور + سطر وصف. الضغطة الأولى على الخدمة، والثانية تدخل حديث المختص. ميرا، منصور، سارة، جلال أمثلة؛ الترتيب النهائي بحسب أولويات اليوم (البيت والطعام أولًا).

### الصورة 5 — الحساب (مرجع الحساب)
![الحساب](mahra-design/05-profile.jpg)
**القرار:** بطاقات للتفضيلات، العناوين المحفوظة، السيرة الذاتية، الخصوصية، إعدادات الصوت. المفاتيح واضحة الحالة، وللخصوصية حضور بصري كامل.

> ملاحظة: النص الأصلي للطلب ربط الصور بأدوار مختلفة عن محتواها (مثلًا «الأولى لعرض المختصين»). اعتُمد هنا الربط بحسب المحتوى الفعلي. يُراجَع مع المالك إن كان المقصود غير ذلك.

## 3.5 الصوت واللهجة
- **مهرة:** صوت أنثوي واحد ثابت (Veda) في كل اللغات.
- **مع المتحدث بالعربية:** تتحدث **باللهجة الإماراتية** (مثل: «هلا والله»، «أبشر»، «الحين»، «شو تحتاج»، «وايد»). مع غير العرب تتبع لغة العميل ولهجته.
- **الوكلاء:** لكل وكيل صوته وجنسيته ولهجته، ويتحدثون بلغة العميل. لا تُفرض عليهم الإماراتية:

| الوكيل | اللهجة والجنسية |
|---|---|
| جلال (السيارات) | أردني |
| راشد (المعاملات الحكومية) | **إماراتي** (استثناء: يمثل جهة إماراتية وحيدة) |
| فيصل (البحث) | سعودي |
| خالد (الهندسة والمقاولات) | مصري |
| أ. عمر (التعليم) | مصري |
| طارق (التقنية) | مصري |
| ليلى (المشتريات) | سورية |
| سارة (إدارة المنزل) | سورية |
| منصور (الخرائط) | سوري |
| طلال (الصيانة) | أردني |
| كريم (التنقل والسفر) | سعودي |
| دانة (الفعاليات والستايل) | أردنية |
| نورة (الطهي) | لبنانية |
| ريم (التجميل والعناية الشخصية) | لبنانية |
| ميرا (التوظيف) | لبنانية |

القاعدة: خمس لهجات (أردنية، لبنانية، سورية، مصرية، سعودية)، بلا مغاربية. مهرة إماراتية، وراشد إماراتي استثناءً لأنه يمثل «تروثفل لخدمات التخليص» وحدها. التوزيع مقترح قابل للتغيير. مع غير الناطقين بالعربية يتحدث الوكيل بلغة العميل مع الحفاظ على جنسيته وصوته.

- **الواجهة المكتوبة** (الأزرار والقوائم): عربية فصحى مبسطة ثابتة؛ اللهجة للمحادثة والصوت فقط.
- **قاعدة:** تُراجَع صياغات اللهجة مع متحدث إماراتي أصلي قبل الإطلاق، ولا تُفرض على من يتحدث بلهجة أخرى بل تُرافق نبرته (G-07).

## 4. الحركة

- لكل خدمة صورة مرتبطة بعملها وحركة قصيرة داخل بطاقتها (≤ 600ms، لا تكرار لانهائي على البطاقات).
- حركة الكرة: استماع (نبض/توسع)، تفكير (دوران بطيء)، رد (موجة تتبع الصوت)، صمت (سكون).
- احترم `prefers-reduced-motion` / إعداد تقليل الحركة: استبدل الحركة بتغيير حالة ثابت (لون/نص) دون فقدان المعنى.

## 5. معيار القبول

تُراجع الواجهة على **هاتف صغير** بالعربية والإنجليزية، مع **تكبير النص** و**تقليل الحركة**. يُختبر مساران كاملان:

1. **اختيار خدمة والوصول إلى المختص** (≤ ضغطتين، يصل السياق معه).
2. **بدء حديث من الشريط السفلي، تلقي رد بلغة العميل، ثم إيقافه.**
